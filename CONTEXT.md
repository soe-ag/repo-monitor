# Repo Monitor domain glossary

## MCP server

A local process that speaks the Model Context Protocol and makes Repo Monitor information available to an MCP client.

## MCP tool

A named, validated operation that an MCP client can call. Repo Monitor's first tools are read-only.

## Repository health

The current observable condition of a repository, including scan status, checklist findings, dependency findings, build status, and deployment status.

## Attention item

A repository health observation whose status indicates that a person may need to investigate or act.

## Connection status

The state of Repo Monitor's configured GitHub connection, without including credentials.
